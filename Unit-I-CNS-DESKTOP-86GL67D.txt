What is a Computer Network? 
A Computer Network is a collection of two or more computers or devices connected together so they can 
communicate, exchange data, and share resources (such as printers, files, software, and Internet 
connection). 
A network may be connected using: 
• Wired cables (Ethernet, Optical Fiber)  
• Wireless technology (Wi-Fi, Bluetooth,  
Cellular Network)  
 
Simple Definition (Exam View) 
A computer network is a group of  
interconnected computers and devices  
that communicate with each other to  
share data, hardware, software, and  
Internet resources.

➢ Network Software (BE Computer Engineering) 
Network software defines how computers communicate with each other. It consists of protocols, layers, 
services, and communication rules that allow devices to exchange information correctly. 
 
1. Protocol Hierarchies (Layered Architecture) 
 
What is a Protocol? 
A protocol is a set of rules and standards that  
govern how data is transmitted and received  
over a network. 
 
Exam Definition 
A protocol is a set of rules that defines how two  
or more devices communicate and exchange  
data over a computer network. 
 
Real-Life Example 
Imagine sending a letter. 
Both the sender and receiver follow rules: 
• Correct address  
• Postal code  
• Stamp  
• Envelope  
 
Similarly, computers follow protocols like TCP/IP to exchange data. 
 
What is a Protocol Hierarchy? 
Instead of performing all networking tasks together, communication is divided into multiple layers, where 
each layer performs a specific function. 
Each layer: 
• Provides services to the layer above.  
• Uses services from the layer below.  
Working 
1. User sends data.  
2. Data moves from the top layer to the bottom layer.  
3. Each layer adds its own information (header).  
4. Data travels through the network.  
5. At the receiver, headers are removed layer by layer.  
6. Original data reaches the application.  
This process is called Encapsulation and Decapsulation. 
 


=== Page 17 ===
Why Layering is Needed? 
• Simpler design  
• Easier troubleshooting  
• Independent development  
• Standardization  
• Better interoperability  
 
Advantages 
• Modular design  
• Easy maintenance  
• Flexibility  
• Standard communication  
• Easy upgrades  
 
Disadvantages 
• Extra processing  
• More overhead  
• Slight communication delay  
 
Real-Life Example 
When opening a website: 
1. Browser creates request.  
2. Transport layer prepares segments.  
3. Network layer adds IP address.  
4. Data Link layer creates frames.  
5. Physical layer sends bits.  
Receiver performs the reverse process. 
 
2. Design Issues for Layers 
Each network layer has specific design responsibilities. 
Major Design Issues 
1. Addressing 
Every device needs a unique address. 
Example: 
• IP Address  
• MAC Address  
Real-Life Example: Every house has a unique postal address. 
 
2. Error Control 
Detects and corrects transmission errors. 
Methods: 
• Checksum  
• CRC  
• Acknowledgement (ACK)  
Example: If a file download is corrupted, missing packets are retransmitted. 
 
3. Flow Control 
Controls the rate of data transmission. 
If the sender is faster than the receiver, the receiver's buffer may overflow. 

=== Page 18 ===
Example: A teacher speaks slowly so students can understand. 
 
4. Routing 
Determines the best path for data. 
Routers select the shortest or fastest route. 
Example: Google Maps chooses the quickest route. 
 
5. Multiplexing 
Multiple users share one communication channel. 
Example: Many people use the same mobile tower simultaneously. 
 
6. Segmentation and Reassembly 
Large messages are divided into smaller packets and later reassembled. 
Example: A large book is packed into several boxes before shipping. 
 
7. Reliability 
Ensures data reaches the destination correctly. 
Methods: 
• ACK  
• Retransmission  
• Sequence numbers  
 
8. Security 
Protects data using: 
• Encryption  
• Authentication  
• Firewalls  
 
Advantages 
• Reliable communication  
• Error-free transmission  
• Better security  
• Efficient routing  
• Improved performance  
 
Disadvantages 
• Complex implementation  
• Increased processing  
• More protocol overhead

6. Relationship Between Services and Protocols 
 
 
Service 
A service is what a layer provides to the layer above it. 
It describes what is offered, not how it is implemented. 
Example 
The transport layer provides reliable delivery to applications. 
 
Protocol 
A protocol defines how two corresponding layers communicate. 
It specifies: 
• Message format  
• Timing  
• Error handling  
• Data exchange rules  
 
Relationship 
• Service = What is provided.  
• Protocol = How the service is implemented.  
Protocols implement the services offered by each layer.

➢ Unit I: Reference Models – OSI Model and TCP/IP Model (BE Computer Engineering) 
Reference models provide a standard framework for understanding how data is transmitted over a 
computer network. Instead of handling all communication in one step, networking tasks are divided into 
layers. 
 
What is a Reference Model? 
 
Definition 
A Reference Model is a conceptual framework that divides the communication process into multiple layers. 
Each layer performs a specific function and communicates with its adjacent layers. 
Exam Definition 
A reference model is a layered framework that standardizes the communication process between 
network devices by dividing networking tasks into separate layers. 
 
Why are Reference Models Needed? 
Without layers: 
• Communication becomes complex.  
• Troubleshooting is difficult.  
• Devices from different manufacturers may not communicate.  
With layers: 
• Standardization  
• Easy maintenance  
• Better interoperability  
• Modular design  
 
Real-Life Example 
Think of sending a courier parcel. 
Different departments perform different jobs: 
1. Customer Service accepts the parcel.  
2. Packing Department packs it.  
3. Transportation moves it.  
4. Local Delivery delivers it.  
5. Receiver gets the parcel.  
Similarly, networking is divided into layers.

Working of OSI Model :- 
 
Step-by-Step 
1. User writes an email.  
2. Application Layer prepares data.  
3. Presentation Layer encrypts it.  
4. Session Layer creates a session.  
5. Transport Layer divides data into segments.  
6. Network Layer adds IP address.  
7. Data Link Layer creates frames.  
8. Physical Layer converts frames into bits.  
9. Bits travel through the network.  
10. Receiver removes headers in reverse order (Decapsulation).  
11. Original message reaches the application.  
 
Advantages of OSI Model 
• Standardized architecture  
• Easy troubleshooting  
• Modular design  
• Easy protocol replacement  
• Vendor independence  
• Better learning model  
 
Disadvantages of OSI Model 
• Complex implementation  
• Seven layers increase overhead  
• Mostly theoretical  
• Rarely implemented exactly as defined

➢ Unit I – Narrowband and Broadband Communication Systems 
Communication systems are classified based on the bandwidth they use. The two major types are: 
1. Narrowband Communication System  
2. Broadband Communication System  
 
What is Bandwidth? 
 
Definition 
Bandwidth is the range of frequencies that a communication  
channel can carry. 
It is measured in Hertz (Hz). 
• Higher bandwidth = More data transmitted per second.  
• Lower bandwidth = Less data transmitted per second.  
Exam Definition 
Bandwidth is the difference between the highest and lowest  
frequencies that can be transmitted through a communication channel. 
 
Real-Life Example 
Imagine a highway. 
• Narrow road (1 lane) → Few vehicles can travel at a time (Narrowband).  
• Wide highway (6 lanes) → Many vehicles can travel simultaneously (Broadband).  
Similarly: 
• Narrow bandwidth carries less data.  
• Broadband carries much more data.  
 
1. Narrowband Communication System 
 
Definition 
A Narrowband Communication System uses a  
small range of frequencies (low bandwidth) to  
transmit data. 
It is mainly designed for voice communication  
and low-speed data transmission. 
 


=== Page 44 ===
Exam Definition 
A narrowband communication system uses a small bandwidth to transmit low-speed data and voice 
signals. 
 
Working of Narrowband Communication 
1. Sender generates data or voice.  
2. Data is converted into electrical signals.  
3. Signals are transmitted over a low-bandwidth channel.  
4. Receiver receives and converts the signals back into data or voice.  
Because only a small frequency range is available: 
• Data transfer is slower.  
• Fewer signals can be transmitted simultaneously.  
 
Characteristics 
• Small bandwidth  
• Low data transfer rate  
• Mostly analog communication  
• Supports voice better than multimedia  
• Lower equipment cost  
 
Real-Life Example 
Example 1: Traditional Landline Telephone 
When you make a call using an old telephone: 
• Only your voice is transmitted.  
• The telephone channel uses approximately 300 Hz to 3400 Hz.  
This is a narrowband system. 
Example 2: Dial-up Internet 
Older Internet connections using telephone lines provided speeds of about 56 kbps, making them 
narrowband. 
 
Applications 
• Landline telephones  
• V oice communication  
• Walkie-talkies  
• Fax machines  
• Pager systems  
 
Advantages 
• Low installation cost  
• Simple technology  
• Low power consumption  
• Reliable for voice communication  
• Easy maintenance  
 
Disadvantages 
• Very slow data transmission  
• Cannot support HD video  
• Unsuitable for large file transfers  
• Limited bandwidth  
• Poor multimedia performance
